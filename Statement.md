# Project Statement

## Problem Statement
In manual systems, managing café orders can be difficult and error-prone, especially when calculating the total bill. The proposed project could be a potential solution for this.

## Scope Of The Project
The proposed project can be used to:
1. Display the Menu of the Café.
2. Add items to cart and check the total
3. View the cart
4. Remove the added item.
5. Clear the cart.
6. Generate the bill.
7. Calculate the GST@(5%).
8. Give a discount of 10% on the total amount if the total reaches Rs1000/-.

## Target Users
The target users of this project could be:
1. Café customers
2. Café staff
3. Students who are new to the Python programming language

## High-Level Features
1. Display Menu
2. Select an item
3. Adding items to cart
4. Removing items from cart
5. Clearing the cart
6. Generating the bill
7. Calculating GST
8. Calculating discounts
9. Simple command-line interface
